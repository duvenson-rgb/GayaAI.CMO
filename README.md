# GayaAI.CMO

Operating repo for the Gaya CMO agent, which runs on a schedule in the cloud.

- `CLAUDE.md`: the operating manual. Read at the start of every run.
- `playbooks/`: one playbook per department (reach, acquisition, conversion, expansion).
- `log/runs.md`: one line per run.
- `learnings.md`: results of finished experiments.
- `references/`: viral reference posts.
- `.claude/skills/`: skills the agent can use (gaya-design, gaya-linkedin-weekly, podcast-clipper, ishikawa-method).
